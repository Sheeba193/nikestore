# NikeStore - A Parody Ecommerce Platform

## About This Project

NikeStore is a humorous parody ecommerce shop dedicated to selling shoes with a Nike store twist. This project showcases a fully functional online shopping experience where users can browse through a curated collection of footwear, manage their shopping cart, and simulate the checkout process.

Built with modern web technologies, NikeStore demonstrates key ecommerce features including product listings, filtering, cart management, and user-friendly navigation—all wrapped in a playful, parody-style interface.

## Features

- 👟 **Product Catalog** - Browse a wide selection of shoe products with detailed descriptions and pricing
- 🛒 **Shopping Cart** - Add, remove, and manage items in your cart with real-time updates
- 🔍 **Product Filtering** - Search and filter shoes by category, price, and other attributes
- 💳 **Checkout Simulation** - Experience a streamlined checkout flow
- 📱 **Responsive Design** - Fully responsive interface that works seamlessly on desktop and mobile devices
- ⚡ **Fast Performance** - Built with React and Vite for optimal speed and user experience

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Sheeba193/nikestore.git
cd nikestore
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```
